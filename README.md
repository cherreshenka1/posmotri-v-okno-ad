# Посмотри в окно

Приложение для поиска и просмотра видео по городам и времени суток.

## Описание проекта

«Посмотри в окно» — это интерактивное веб-приложение, которое позволяет пользователю:

- Просматривать видео с видами из окон разных городов
- Фильтровать видео по городу и времени суток (утро/день/вечер/ночь)
- Выбирать видео из списка карточек для просмотра в главном плеере
- Загружать дополнительные видео по кнопке «Показать ещё»

Проект выполнен в рамках учебной программы и представляет собой **дописывание CSS** к уже готовой HTML-разметке и работающему JavaScript-приложению.

## Технологии

- HTML5
- CSS3
  - Flexbox
  - Grid Layout
  - Position (absolute/relative)
  - Псевдоклассы и псевдоэлементы
  - Кастомные чекбоксы

- Методология БЭМ (в именовании классов)

## Функциональность

Приложение обладает следующим функционалом:

1. **Поиск видео** — форма с полями ввода города и выбора времени суток
2. **Фильтрация** — после отправки формы список карточек обновляется
3. **Просмотр видео** — клик по карточке меняет видео в главном плеере
4. **Подгрузка контента** — кнопка «Показать ещё» добавляет 5 новых карточек
5. **Обработка ошибок** — при проблемах с загрузкой данных показывается сообщение об ошибке
6. **Прелоадеры** — во время загрузки данных отображается анимация
